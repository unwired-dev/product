On the Mac, the Draft editor page opens the Mac composer's Slash Command Menu when `/` is typed first in a body block. The menu hangs under the `/`, whose left edge the page now reports with the caret's line, the page hands it Return, Tab, the arrows and Escape, and a chosen block is one page edit that one Undo reverts.
