On iPad and iPhone, the Slash Command Menu lists the Writing tools that apply after Insert, in the format bar's groups: Generate a Draft…, Suggest Reply on a reply, and the text tools while the body has text. Typing filters them, and choosing one removes the typed command and runs it as the format bar does (#2687).
