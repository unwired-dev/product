On iPad and iPhone, typing `/` at the start of a body block opens the Slash Command Menu with the Basic Blocks: Text, Heading 1 to 3, Bulleted List, Numbered List, Quote and Code Block. Typing filters them; a tap, Return or Tab sets the block and removes the typed command as one Undo step. An iPad hardware keyboard moves the highlight with Up and Down Arrow and closes the menu with Escape (#2656).
