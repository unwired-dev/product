# Agent access

[Domain index](../../GLOSSARY.md) · [requirements](../product/agent-access.md)

These terms describe the confirmed post-launch Agent access requirements.
They do not establish implementation or launch scope.

## Language

**External Agent**:
An assistant outside Unwired that a user authorizes to access their mail through
Unwired. It is distinct from On-Device Mail Assistance.
_Avoid_: On-Device Mail Assistance, Trusted Device

**Agent Connection**:
A separately enabled relationship through which a user authorizes an External
Agent to access selected Mailbox Connections within one Mail Profile in Unwired.
_Avoid_: Mailbox Connection, Mailbox Authorization, Product Sign-In
