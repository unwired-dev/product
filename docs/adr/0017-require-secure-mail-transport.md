# Require secure mail transport

IMAP, SMTP, POP3, and Exchange Web Services connections will require TLS 1.2 or newer with valid server identity before authentication. The client will prefer implicit TLS, permit STARTTLS only when successfully negotiated before credentials are sent, reject plaintext authentication and certificate failures, and provide no invalid-certificate override. Device-side setup may use DNS email-service discovery defined by [RFC 6186](https://www.rfc-editor.org/rfc/rfc6186.html) or a bundled reviewed provider catalog, but the user reviews discovered endpoints and may configure them manually; addresses and server settings never go to the product backend. This deliberately sacrifices compatibility with obsolete or misconfigured servers to protect mailbox credentials and content, following [RFC 8314](https://www.rfc-editor.org/rfc/rfc8314.html).
