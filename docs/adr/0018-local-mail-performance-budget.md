# Set a local mail performance budget

At the 95th percentile on the current supported reference iPhone running a release build with a warm encrypted cache, the sidebar and initial thread list must appear within one second from app-launch entry to first rendered content, and cached mailbox switching and cached body opening must complete within 200 milliseconds from user selection to rendered content. The fixture contains at least two populated mailbox connections, each with 50 initially available messages and a completed historical metadata backfill; each body-opening measurement uses a cached body. Synchronization must not cause any main-thread stall longer than 100 milliseconds, measured by main-thread responsiveness instrumentation as an absolute cap rather than a percentile. Provider and network latency will be measured and reported separately rather than counted against local rendering. These budgets make the local store the presentation source of truth and require synchronization, decryption, parsing, and persistence work to stay off the main thread.
