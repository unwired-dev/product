# Sync mail workflow preferences, not device state

Mail-handling choices should follow the user across trusted devices, while choices constrained by one device should remain local. Inbox behavior, read-state rules, swipe assignments, compose behavior, signatures, templates, category configuration, and per-connection notification and read-receipt policies therefore use End-to-End Encrypted Product Sync. Appearance, operating-system notification permission and presentation, generic notification fallback, remote-content and download behavior, storage controls, diagnostics, and settings-navigation state remain device-local. Provider credentials continue to live only in each device's Keychain. This boundary preserves a consistent mail workflow without making hardware, operating-system permissions, network exposure, storage use, or secrets behave as portable account data.
