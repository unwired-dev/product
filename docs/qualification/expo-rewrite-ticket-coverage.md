# Expo rewrite ticket coverage

Publication and scope audit: 2026-09-09.

The accepted rewrite and its follow-ups are represented by **78 GitHub issues**:
37 Gmail-first beta slices, 39 approved follow-ups, and two public-release steps
made explicit by the completeness audit. All titles, bodies, open states,
`ready-for-agent` labels, and **111 native blocking dependencies** were read back
from GitHub. The resulting graph has no cycles or redundant direct edges.
This is a publication snapshot; GitHub remains the source of current work status
under [the issue-tracker policy](../agents/issue-tracker.md).

The audit compared the breakdown with the recorded interview decisions in
[the rewrite research](../research/expo-react-native-rewrite.md) and accepted
[ADR 0059](../adr/0059-replace-the-client-for-a-shared-cross-platform-product.md)
through [ADR 0064](../adr/0064-isolate-mobile-and-macos-native-dependencies.md).
It found no further agreed feature without a ticket after the corrections below.

## Preserved scope boundaries

The Apple deployment floor remains iOS/iPadOS/macOS 27. The maintainer authorized
implementation without present native validation; [#623](https://github.com/unwired-dev/product/issues/623) retains the native
release gate. Ticket publication provides no additional native build, runtime,
provider, AI, or performance evidence.

Convex remains required, with no separate outage mode or alternate send
coordinator. [#627](https://github.com/unwired-dev/product/issues/627) owns the one-time unused development reset; [#600](https://github.com/unwired-dev/product/issues/600)
and [#601](https://github.com/unwired-dev/product/issues/601) retain normal enrollment and recovery. No database reset has run.

On-premises Exchange/EWS and POP3 were historical prototype context, and additional
unnamed sign-in providers were not selected. They are not added as commitments.
The accepted release is a focused Gmail product; historical prototype documents
do not silently add full feature parity to its scope.
